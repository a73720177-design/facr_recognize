# 얼굴·신체·손 관절 인식

앙치킨 영상인식 프로젝트의 Python 구현입니다.

코딩이 처음이라면 [입문자용 프로젝트 안내](BEGINNER_GUIDE.md)에서 용어·실행 방법·기능 원리를 먼저 읽어보세요.

전체 기능, 변경 이력, 실행 방법, 검증 결과는 [프로젝트 작업 정리](PROJECT_SUMMARY.md)를 참고하세요.

Python 3.14 / Windows용 OpenCV + MediaPipe Tasks 예제입니다. `.venv`에 라이브러리를 설치하고 `models/`에 얼굴·신체·손 모델 세 개를 다운로드했습니다. 이후 영상 추론은 로컬에서 수행하며 영상 저장 및 업로드 기능은 없습니다.

## 실행

```powershell
cd C:\angchicken
.\.venv\Scripts\python.exe recognition.py
# 다른 카메라
.\.venv\Scripts\python.exe recognition.py --camera 1
# 영상 파일
```

Q 또는 Esc로 종료합니다. 카메라가 열리지 않으면 Windows 카메라 권한과 다른 앱의 카메라 사용 여부를 확인하세요. 기본 웹캠 화면은 거울 모드이며 `--no-mirror`로 해제합니다.

화면 상태·표정·동작·손 이름·종료 안내는 한글로 표시합니다. Pillow와 Windows 맑은 고딕 글꼴(`C:\Windows\Fonts\malgun.ttf`)을 사용합니다.

인식 창은 자동 최대화 없이 원래 영상 크기로 표시됩니다.

## 손가락 마디 관절

가위는 두 가지 모양을 지원합니다: 검지·중지를 펴는 V 모양, 엄지·검지를 펴고 중지·약지·소지를 접는 모양. 검지만 펴고 엄지를 접은 동작은 가위로 분류하지 않습니다.

중지만 펴고 검지·약지·소지를 접으면 해당 손 전체에 여백을 포함한 블러를 자동 적용합니다. 엄지 상태는 상관없습니다. 마지막 감지 후 0.6초 동안 유지하며, 손 특징점이 보이면 현재 위치를 따라갑니다. 손이 사라지면 마지막 영역을 잠깐 가립니다. 손 관절 표시도 블러 안에 가려집니다. 현재 차단 대상은 `중지 올리기`이며 다른 문화권의 모든 손가락 욕을 판별하는 기능은 아닙니다. 가림·빠른 움직임·모델 미검출 시 놓칠 수 있습니다.

손 움직임도 시간에 따라 추적하여 `손 흔들기`, `왼쪽 이동`, `오른쪽 이동`, `위로 이동`, `아래로 이동`을 표시합니다. 좌우 이동 방향은 화면 기준입니다. 손바닥 중심의 최근 1.5초 궤적에서 충분한 좌우 이동과 두 번 이상의 방향 전환이 있으면 손 흔들기로 인식합니다. 단방향 이동은 최근 0.45초 이동량으로 판단합니다. 흔들기는 손 모양과 별도로 판별하므로 주먹을 좌우로 흔들어도 감지됩니다.

카메라를 고정하고 손을 좌우로 2~3회 흔들어주세요. 카메라 자체의 움직임과 손 움직임은 구분하지 않습니다. 손이 사라지거나 좌우 손 분류가 바뀌거나 위치가 크게 튀면 기록을 초기화합니다. 같은 좌우 분류의 손이 두 개 잡히면 추적을 보류합니다. 여러 사람의 손을 지속 식별하는 기능은 아닙니다.

최대 두 손의 21개 특징점과 연결선을 표시합니다. 손목 옆에는 모델이 분류한 좌우 손과 신뢰도를 표시합니다. 관절 번호는 `--hide-hand-ids`로 숨길 수 있습니다.

| 번호 | 위치 |
| --- | --- |
| 0 | 손목 |
| 1–4 | 엄지: CMC, MCP, IP, 끝 |
| 5–8 | 검지: MCP, PIP, DIP, 끝 |
| 9–12 | 중지: MCP, PIP, DIP, 끝 |
| 13–16 | 약지: MCP, PIP, DIP, 끝 |
| 17–20 | 소지: MCP, PIP, DIP, 끝 |

MCP는 손바닥과 손가락의 연결 관절, PIP는 손가락 중간 관절, DIP는 끝에 가까운 관절입니다. 엄지는 CMC·MCP·IP 구조를 사용합니다.

상단에는 엄지 IP 및 나머지 손가락 PIP의 추정 각도(도)를 표시합니다. 곧게 편 관절은 약 180도이며 굽히면 작아집니다. `finger_angles()`는 모델이 추정한 3D 좌표로 각도를 계산합니다. 가려진 손가락이나 빠른 움직임에서 정확도가 낮아질 수 있습니다.

`hands.hand_landmarks[손 인덱스][관절 번호]`의 `x`, `y`, `z`로 좌표에 접근할 수 있습니다. `x`, `y`는 영상 너비·높이로 정규화한 값이며 화면 픽셀은 각각 너비·높이를 곱해 계산합니다. `z`는 손목 기준 상대 깊이입니다. `hands.hand_world_landmarks`는 모델이 추정한 3D 좌표입니다. 손 인덱스는 프레임마다 달라질 수 있으며 개인 식별 ID가 아닙니다. 화면을 뒤집어도 관절 번호와 좌우 손 표시는 읽을 수 있게 그립니다.

## 얼굴과 신체 기능

`엄지 올리기`도 양손에서 인식합니다. 검지·중지·약지·소지를 접고 엄지만 펴서 화면 위쪽으로 올리세요. 접힌 네 손가락과 엄지의 펴짐·방향·높이를 함께 확인하여 바위와 구분합니다. 엄지를 옆이나 아래로 향한 동작은 엄지 올리기로 판별하지 않습니다. 화면을 거울 모드로 바꿔도 위쪽 방향은 동일합니다. 가려진 엄지는 인식하기 어려울 수 있습니다.

가위바위보는 영상의 2D 관절 위치와 3D 추정 좌표를 함께 사용합니다. 영상 너비·높이를 반영한 거리로 손가락의 펴짐과 손목에서 손끝까지의 뻗음을 판단하며, 2D에서 판단하기 어려우면 3D를 사용합니다. 보자기는 엄지 뿌리 관절이 곧게 펴져야 한다는 조건을 제거하고 엄지 끝마디의 펴짐과 검지에서의 벌어짐을 확인합니다. 정면 손바닥의 깊이 추정 오차에 덜 민감하지만 손가락이 가려지거나 카메라 방향으로 향하면 여전히 판별이 어려울 수 있습니다.

한쪽 눈 감기는 `왼쪽 눈만 감기` / `오른쪽 눈만 감기`로, 두 눈을 감으면 `양쪽 눈 감기`로 표시합니다. 좌우는 인물의 신체 기준입니다. 감은 눈의 blendshape 점수가 0.55 이상이고 반대 눈은 0.30 이하일 때 한쪽 눈 감기로 판별합니다. 순간적인 비대칭 깜빡임도 감지될 수 있으며 윙크 의도를 구별하는 기능은 아닙니다.

각 손에 `가위` / `바위` / `보자기` 등을 표시합니다. 가위는 검지·중지 V 모양과 엄지·검지 변형을 지원합니다. 네 손가락을 굽히면 바위이며, 엄지를 위로 펼친 경우 엄지 올리기로 구분합니다. 엄지를 포함해 다섯 손가락을 펴면 보자기입니다. 중간 자세나 다른 손 모양은 `판별 불가`로 표시합니다. 2D 위치와 3D 추정 좌표를 함께 사용하지만 가림·촬영 각도에 따라 오인식할 수 있습니다. `recognize_hand_gesture()`에서 기준을 조정할 수 있습니다. 손 이름 옆 퍼센트는 좌우 손 분류 신뢰도이며 손 동작 신뢰도가 아닙니다.

한 명의 얼굴과 신체를 추적합니다. 얼굴 특징점 및 미소·눈 감기·입 벌리기를 감지하고, 신체 관절을 표시하며 팔 들기를 판별합니다. 얼굴을 직접 등록하면 등록된 이름을 표시합니다.

## 얼굴 등록·식별 및 특징 분석

```powershell
# 이름을 지정해 웹캠 실행
.\.venv\Scripts\python.exe recognition.py --register "홍길동"
# 등록 이후 일반 인식 실행
.\.venv\Scripts\python.exe recognition.py
```

등록 모드에서 한 명만 카메라를 보고 얼굴을 충분히 크게 보여준 뒤 S를 누르세요. 조명이나 고개 방향을 조금 바꾸어 3~5회 저장하면 여러 조건의 특징을 등록할 수 있습니다. 이름별 최대 10개 표본을 저장합니다. 다른 사람을 등록하려면 프로그램을 종료하고 다른 이름으로 다시 실행합니다.

YuNet으로 얼굴을 검출·정렬하고 SFace로 얼굴 특징 벡터를 추출합니다. 등록 표본과 코사인 유사도를 비교하며 기본 기준 0.45 미만이거나 두 이름의 점수가 비슷하면 미등록 / 판별 불가로 표시합니다. 유사도는 확률이 아닙니다. `--face-threshold 0.50`처럼 기준을 높이면 더 엄격해집니다. 화면에 여러 얼굴이 있거나 얼굴이 너무 작으면 등록하지 않습니다.

이름과 특징 벡터는 `data/faces.json`에 로컬 저장합니다. 원본 얼굴 사진은 저장하지 않습니다. 등록 정보를 모두 지우려면 프로그램을 종료하고 이 파일을 삭제하세요. 새 환경에서 최초 실행 시 YuNet·SFace 모델 두 개도 추가 다운로드합니다. 사진·영상으로도 인식될 수 있으며 생체 확인 기능은 포함하지 않습니다.

얼굴 특징 분석은 얼굴 세로/가로 비율, 눈 중심 간격/얼굴 폭, 입 너비/얼굴 폭, 코 길이/얼굴 높이를 표시합니다. MediaPipe 특징점의 영상상 거리를 사용하므로 고개 각도·표정에 따라 값이 달라집니다. 이름 식별은 이 비율 대신 SFace 특징 벡터를 사용합니다.

참고: [OpenCV 얼굴 검출·인식 공식 예제](https://docs.opencv.org/4.11.0/d0/dd4/tutorial_dnn_face.html).
